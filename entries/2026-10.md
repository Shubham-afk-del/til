## 23 Oct 2026

- **Find Pivot Index (prefix sums, brute force first):** I wrote `pivot_index` that checks every index `i` and compares `sum(nums[:i])` with `sum(nums[i+1:])`, returning `-1` when no index balances, with test calls for edge cases like `[5]` and `[2, 1, -1]`. Each slice and sum is O(n), so this version is O(n^2) time with O(n) extra space per slice, which is why the next step is a running left sum against `total - left - nums[i]` for O(n).

## 22 Oct 2026

- **Top K Frequent Elements (hash map + sort):** I counted each number in a dictionary `box`, then sorted `box.items()` with `key=lambda x: x[1]` and `reverse=True` and took the first `k` keys. Counting is one O(n) pass and sorting the m distinct numbers costs O(m log m), so a heap or bucket sort would be the next step to get below a full sort.
