## 5 Nov 2026

- **Encode and Decode Strings (length prefix, decode in progress):** I wrote `encode` from memory to put `str(len(s)) + "#"` in front of every string, so a `#` inside a word like `"a#b"` cannot break the format. My `decode` finds the separator with `strs.index("#", i)` but then slices with the length text itself instead of `int(strs[i:j])`, so the fix I am working on is to read exactly that many characters after `j + 1` and move `i` past them.

- **Contains Duplicate (set, stop at the first repeat):** I rewrote it with a set instead of a count dict: for each number I return `True` as soon as it is already in the set, otherwise `box.add(i)`, and `return False` only after the loop. It stops at the first repeat instead of counting every number first, but the set can still grow to hold all n numbers, so the extra space is O(n), not O(1).
